# Kālabhairava Names

Explore the names and attributes of Lord Kālabhairava through searchable collections, random selection, and detailed explanations.

<p align="center">
  <strong>ॐ कालभैरवाय नमः</strong>
</p>

## Visit the website

**[Open Kālabhairava Names](https://mradhikari.github.io/kaalbhairav/)**


## Features

- **Two collections:** Browse the 108 Names and 1000 Names collections.
- **Random name:** Draw a random name and view its meaning and full description.
- **Search:** Find names by name, meaning, or number.
- **Sorting:** Arrange the list numerically, in reverse numerical order, alphabetically, or randomly.
- **Meaning groups:** Organize names into thematic categories.
- **Detailed explanations:** Select any name to read its meaning and expanded description.
- **Responsive design:** Use the website on desktop and mobile devices.
- **Theme support:** Supports light and dark appearance, including the device's preferred color scheme.

## Getting started

This project is a standalone HTML website. It does not require a framework, package installation, build process, or backend server.

1. Clone or download this repository.
2. Keep `index.html` in the repository's root directory.
3. Open `index.html` in a modern web browser.
